Voice answers for WaniKani & BunPro

Site Access

Kikoe can't run on WaniKani or BunPro until the browser is allowed to run it there. Safari asks for this separately from turning the extension on, and won't prompt you for it on its own.

If that button doesn't do anything, grant it directly:

  • iPhone / iPad: Settings > Apps > Safari > Extensions > Kikoe, then set each site to Allow.
  • Mac: Safari > Settings > Extensions > Kikoe, then set each site's access to Allow.
  • Either: open a review page and choose Allow from Kikoe's icon in Safari's toolbar.

Microphone Access

Open a WaniKani or BunPro review page and start listening. When your browser asks for microphone access, choose Allow.
